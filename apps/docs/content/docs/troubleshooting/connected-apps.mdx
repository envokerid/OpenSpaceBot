---
title: Connected apps
description: Recover a connection or account grant
---

If Connect fails, check the integration URL, provider credentials and server
runtime installation. OAuth requires a supported MCP authorization server
and a correctly registered callback. Hosted deployments should use the
workspace's public HTTPS address with `/oauth/mcp/callback` forwarded to the app.

For a localhost redirect opened on another device, copy the complete failed
callback URL into the Connect screen. For a QR-only provider, continue the same
pending account on another screen and scan it with the provider's phone app.

A connected account is not automatically available to a bot: grant that exact
account under the bot's Access settings. If a provider revokes authorization,
disconnect and connect again, then approve the new account. Never automatically
retry a timed-out write; first check whether it completed at the provider.

See [OpenClaw runtime](../connected-apps/openclaw.mdx).
