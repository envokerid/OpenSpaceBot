# Retired room voting

Room proposals, voting, judges, typing bots, verdict drafts, and automatic
elections have been removed. Group chats again use the original default
responder and explicit @mentions. Bot posts do not start new room turns.

Use [Channels](channels.md) for normal conversations and
[In-chat team coordination](room-coordination.md) for teammate handoffs.
The optional Finish together goal mode retains its original coordinator loop.

Historical transcripts remain stored; private proposal histories are no longer
used to construct new turns. Visual verification is left to the user.
